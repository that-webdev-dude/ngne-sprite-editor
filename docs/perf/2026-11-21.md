# Reference measurements for release 1.1.1: 2026-11-21

The owner's full run on branch `chore/release-1.1.1` (`main` at `126de90` with the release's
version changes), the new baseline for further development: every benchmark that keeps a
reference record, on the final code, alone: no other benchmark or E2E ran at the same time.
Records written 08:34–08:42 UTC; the four stroke records (`se-015`, `se-062`) were taken again
08:52–08:55 UTC, each followed by an unrecorded run (Notes).

Environment: Windows 11 10.0.26200, i7-12650H (16 logical processors), 16 GB RAM; installed
Chrome 157.0.8103.80 (new headless), Node 24.15.0. Intel UHD (gen-12lp) and RTX 4060 Laptop
GPU (nvidia/lovelace); every browser benchmark with `PERF_GPU` verified the requested WebGPU
adapter. These are reference-hardware measurements, not SwiftShader.

Method: the unchanged [benchmark scripts](../../tests/perf/README.md), one process at a time,
`PERF_RECORD=1`, `PERF_GPU=intel-uhd` / `rtx-4060`, no `PERF_ID`: each record replaces the
benchmark's own record. The Node benchmarks and the two Chrome benchmarks without a GPU
(`se-042`, `se-044`) ran once without `PERF_GPU`. The cold load includes the GPU warm-up of
[issue #17](https://github.com/that-webdev-dude/ngne-sprite-editor/issues/17).

## Notes

- **Cold load.** Since the warm-up, no load on the RTX 4060 waits for the GPU to wake: its 10
  loads lie between 435 and 928 ms, against 2368 ms for the first load on 2026-11-20. Eight
  of the ten take 880–930 ms, the time to the shell (865–908 ms) and not the app's start
  (DOMContentLoaded 105–114 ms); the warm-up itself took 1042 ms, 772 ms of it page to
  adapter. Intel UHD: one load at 383 ms, the other nine 250–295 ms.
- **Stroke validity.** The first pass's stroke runs were valid by frame count, but the output
  of their unrecorded runs was not logged, so the four stroke records were taken again. Each
  recorded run has the usual frame count, and the unrecorded run right after it agrees within
  1 ms (record / unrecorded, frames in brackets):

  | Record | Intel UHD | RTX 4060 |
  | ------ | --------- | -------- |
  | `se-015-stroke-latency` | 14.5 (738) / 14.7 ms (743) | 13.5 (688) / 13.2 ms (707) |
  | `se-062-stroke-latency-symmetric` | 15.0 (740) / 14.1 ms (664) | 13.8 (703) / 14.4 ms (693) |

  First pass, superseded: `se-015` 14.2 / 12.0 ms, `se-062` 15.2 / 12.8 ms.
- This run is the only baseline in `docs/perf`: the earlier records (checkpoint E, the cloud
  SwiftShader run, the stroke records without the echo, the run of 2026-11-20) were removed
  with it and stay in the repository's history: all of them at `126de90`, all but the run of
  2026-11-20 also in tag `v1.1.0`.
